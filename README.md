# AWS EC2 Static Website Hosting

This project demonstrates hosting a static website on AWS EC2.

### Tech Stack
- AWS EC2 (Amazon Linux 2)
- Apache HTTPD
- Linux Shell Scripting

### Deployment Steps
1. Launch EC2 Instance (t2.micro)
2. Open Security Group Port 80
3. Run the automation script:
   chmod +x install-apache.sh
   ./install-apache.sh
4. Access via Public IP
